# ESG Almaty

ESG Almaty — интерактивный дашборд для анализа устойчивого развития города Алматы.

Проект показывает:

* качество воздуха и уровень PM2.5;
* использование общественного транспорта;
* ESG-показатели районов Алматы;
* экологическое поведение жителей;
* ключевые городские показатели;
* официальные источники данных.

## Технологии

* Next.js
* React
* TypeScript
* Chart.js
* CSS

## Запуск проекта

```bash
npm install
npm run dev
```

Откройте в браузере:

```text
http://localhost:3000
```

Для проверки production-сборки:

```bash
npm run build
```
